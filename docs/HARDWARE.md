# 배선과 부품

전원을 끈 상태에서 배선하고, 첫 통신 시험은 펌프 전원을 분리한 채 진행합니다.

## 추가 부품

MAX485 5V 2개, MAX3485 3.3V 1개(또는 ESP32용 MAX485와 적합한 5V→3.3V RO 레벨변환), 120Ω 종단저항 2개, LED 직렬저항 220~330Ω 4개, 펌프용 MOSFET, 게이트 저항 100Ω, 게이트 풀다운 10kΩ, 역기전력 다이오드, 펌프 기동전류를 감당하는 안정된 외부 3.3V 전원, 배선재가 필요합니다. 사진의 릴레이를 쓰는 경우 5V 코일 전원과 입력 극성을 별도로 확인해야 합니다. 기본 펌웨어는 HIGH=ON MOSFET 회로입니다.

## UNO1 / UNO2 공통 (UNO R3 ATmega328P 기준)

| UNO 핀 | 연결 |
|---|---|
| D0 RX | MAX485 RO |
| D1 TX | MAX485 DI |
| D2 | MAX485 DE와 /RE를 함께 연결 |
| 5V / GND | MAX485 VCC / GND |
| D3, D4 | 각 LED 애노드에 직렬저항; 캐소드는 GND |
| D5, D6 | 각 버튼 한쪽; 다른 쪽 GND (INPUT_PULLUP) |

D0/D1은 업로드 USB UART와 공유하므로 **업로드할 때 MAX485 RO/DI를 분리**하세요. 시리얼 모니터를 열어 디버그 문자열을 보내면 RTU가 깨집니다.

## UNO2만 연결

| 핀 | 연결 |
|---|---|
| A0 | 센서 모듈 AO (DO는 사용하지 않음) |
| D9 | 센서 전원 스위치 제어 |
| D7 | MOSFET 게이트(100Ω 경유); 게이트-GND 10kΩ |
| D8 | 소전류 피에조 수동 부저 +, -는 GND |

센서 전원은 D9로 제어하는 **HIGH 활성 전원 스위치/로드 스위치**를 통해 5V를 공급하는 구성을 권장합니다. 센서 소비전류를 확인하지 않고 GPIO에 VCC를 직접 연결하지 마세요. 스위치 출력에 센서 VCC, GND는 공통입니다. 1초마다 20ms 켠 후 측정합니다. 실제 센서 안정화 시간이 더 길면 펌웨어에서 시간을 늘리세요. 부저가 전자기식/고전류라면 트랜지스터 구동이 필요합니다.

펌프 외부 +3.3V → 펌프 +, 펌프 - → N채널 MOSFET 드레인, 소스 → GND. 다이오드는 펌프 양단에 역방향(캐소드 +3.3V, 애노드 드레인)으로 연결합니다. MOSFET은 UNO의 게이트 전압에서 충분히 켜지고 기동전류를 감당해야 합니다. 노트북 USB나 ESP32의 3V3에서 펌프 전원을 끌어오지 마세요. **3.3V 펌프에 5V를 공급하지 마세요.**

## ESP32 DevKit V3

보드 실크/모듈을 확인하세요. 여기서는 일반 ESP32-WROOM UART2 사용 가능 보드를 가정합니다. ESP32-S3나 PSRAM으로 16/17을 점유한 모델은 핀 변경이 필요합니다.

| ESP32 | MAX3485 |
|---|---|
| GPIO16 RX2 | RO |
| GPIO17 TX2 | DI |
| GPIO21 | DE + /RE |
| 3V3 | VCC |
| GND | GND |

MAX485는 5V 전원 부품입니다. ESP32에 쓰려면 5V로 구동하면서 RO 출력을 적합한 단방향 레벨 시프터로 3.3V에 맞추세요. 모듈의 풀업 저항도 확인해야 합니다. MAX3485를 사용하면 설계가 단순해집니다.

3개 모듈의 A끼리, B끼리 연결하고 기준 GND도 공유합니다. 데이지체인으로 연결하며 물리적 양 끝에만 A-B 120Ω을 둡니다. 내장 종단저항이 있는 모듈은 중복하지 않습니다. 유휴 바이어스는 버스 한 지점에서만 구성하고 모듈의 기존 바이어스를 확인하세요. 서로 다른 제조사의 A/B 표기가 반대라면 데이터시트를 기준으로 확인하세요.

## 레지스터 (0 기반, FC03/06)

| 주소 | 관용 표기 | 의미 | 권한 |
|---|---|---|---|
| 0 | 40001 | ADC 0~1023 (UNO2만 유효) | 읽기 |
| 1 | 40002 | 상대 수분 0~100 (UNO2만 유효) | 읽기 |
| 2 | 40003 | 버튼 비트0/1, 눌림=1 | 읽기 |
| 3 | 40004 | LED 비트0/1, 0~3 | 읽기/쓰기 |
| 4 | 40005 | UNO2 펌프 0/1 | 읽기/쓰기 |
| 5 | 40006 | UNO2 부저 0/1 | 읽기/쓰기 |
| 6 | 40007 | 자동관개 임계값 0~100, 기본30 | 읽기/쓰기 |
| 7 | 40008 | UNO2 자동관개 0/1 | 읽기/쓰기 |

부팅 시 펌프 OFF, 자동 OFF. 마지막 정상 FC03 이후 5초 통신이 없으면 펌프와 자동모드 OFF. 1회 펌프 최대 10초이며 반복 ON 명령은 타이머를 연장하지 않습니다. 자동관개는 수분이 임계값+5 이상으로 회복된 후 임계값 미만으로 내려갈 때 1회 작동합니다. 처음부터 마른 상태에서는 수동 급수로 시작합니다. 건조 상태가 계속되어도 무한 재급수하지 않습니다. UNO2 버튼1은 수동 급수, 버튼2는 펌프/자동 정지입니다. UNO1 버튼은 각각 LED를 토글합니다.

ADC 건조850/습윤350은 예시값입니다. 실제 공기/건조토양/젖은토양을 측정하고 map()의 양 끝을 바꾸세요. %는 체적함수율이 아닌 상대 지표입니다. ADC가 10미만 또는 1013초과이면 펌프와 자동모드를 정지하지만, 중간값으로 나타나는 센서 단선까지 검출하지 못합니다. 수위센서는 없으므로 물통 부족 자동 검출은 구현하지 않았습니다. 첫 시험은 물통을 직접 관찰하세요.
